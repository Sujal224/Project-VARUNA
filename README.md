# VARUNA — Marine Intelligence

> *A premium, AI-powered maritime decision-support system designed to understand the ocean.*

VARUNA transforms complex oceanographic telemetry (Potential Fishing Zones, bathymetric contours, wave currents, sea surface temperature, chlorophyll concentration, cyclone paths) into calm, explainable AI intelligence.

Built for Android with **React Native**, **Expo**, and **TypeScript**.

---

## 🌊 Design Ethos & Architecture

* **Visual Identity**: Oceanic Intelligence (*Dark Mode First*, Luminous Navies `#051424`, Cyan `#22d3ee`, Indigo `#6366f1`).
* **Signature Brand Anchor**: The **VARUNA Orb** — a dimensional glass sphere with an animated internal horizon wave line and controlled aura.
* **Typography**: Contrast between editorial serif (*Playfair Display*) for headlines and technical sans-serif (*Inter*) for telemetry and data readouts.
* **Explainable AI**: Every recommendation is paired with transparent factor matching, confidence scoring, and safety margins.

---

## 📱 Application Screens

1. **Home Screen**: Real-time 4-metric telemetry grid (Sea Temp, Wave Height, Wind Speed, Chlorophyll), VARUNA Insight with animated 87% confidence ring, AI Search Gateway, and Geospatial preview.
2. **Marine Intelligence Map**: Multi-layer ocean canvas with Potential Fishing Zones (PFZ), Chlorophyll concentration overlays, bathymetric contour vectors, and vessel telemetry.
3. **VARUNA AI**: Conversational marine decision support and situational analysis.
4. **Maritime Alert Center**: Calm, structured warning and advisory center for cyclones, high swells, and navigation hazards.
5. **Vessel & Offline System**: Vessel specifications, offline bathymetric tile cache management, and pre-voyage sync.

## 🚀 Running the Project

### Prerequisites
* Node.js (v18+)
* Android Studio / Android Emulator or Expo Go app on a physical Android device

### Start Development Server
```bash
npm run start
```

### Launch Directly on Android
```bash
npm run android
```

### Type Checking
```bash
npm run tsc
```
